# タスク管理アプリ

ブラウザだけで動くシンプルなタスク管理アプリです。サーバーやビルドは不要で、データはブラウザの `localStorage` に保存されます。

## 使い方

`index.html` をブラウザで開くだけで使えます。

```sh
# ローカルサーバーで開く場合
python3 -m http.server 8000
# → http://localhost:8000
```

GitHub Pages を有効にすれば、スマホからも利用できます。

## 機能

- タスクの追加（カテゴリ・優先度・期限つき）
- 完了 / 未完了の切り替え
- タイトルの編集（✎ ボタンまたはダブルクリック、Enter で確定・Esc でキャンセル）
- 削除、完了済みの一括削除
- 「すべて / 未完了 / 完了」の切り替え
- キーワード検索、カテゴリ絞り込み
- 期限順・優先度順・作成順の並べ替え
- 期限切れタスクの強調表示、残り日数の表示
- ダークモード、スマホ対応
- **写真から追加**：手帳のメモやホワイトボードの写真から文字を読み取り、タスクとしてまとめて登録

## 写真から追加

1. 「📷 写真から追加」を押して、写真を撮るか画像を選びます
2. 読み取った文字が 1 行ずつタスク候補として表示されます
   - 行頭の「・」「1.」「□」などは自動で取り除きます
   - 「9/30」「10月3日」「期限：10/5」などの日付は期限として設定されます（年がなければ今日以降の直近の日付）
3. 不要な行のチェックを外し、文字や期限を直してから「○件を追加」を押します

カテゴリと優先度は、入力欄で選んでいるものが使われます。

文字認識は [Tesseract.js](https://github.com/naptha/tesseract.js) を使い、**写真はブラウザの中だけで処理され、外部に送信されません**。初回のみ認識エンジンと日本語データ（十数MB）をダウンロードするため、インターネット接続が必要で少し時間がかかります。印刷された文字やはっきりした字はよく読み取れますが、手書き文字は精度が落ちることがあります。
